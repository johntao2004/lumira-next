# 角色权限委派

权限目录的 `editable` 与角色保存使用同一委派契约。平台权限必须由操作者在全局范围持有；当前已安装插件提供的权限，可由全局持有者或拥有全局 `platform:modules:install` 的角色管理员委派。插件安装权限不能用于委派平台权限、未知权限或已卸载插件的权限，角色预览不能使用插件引导。

角色更新重新校验原有和新增的有效权限，并为涉及的插件引导逐项写入 `role.pluginPermission.bootstrap:<authority>` 审计。退役权限只允许保留或移除。角色删除与用户角色移除仍严格校验原有权限，不使用插件引导。

新账号默认角色始终受公开注册允许列表限制，即使公开注册关闭，也不能删除、停用、扩大数据范围或增加列表外权限。修改前必须在公开注册设置中更换默认角色。该限制在委派校验前返回 `registrationRoleInUse`，避免被插件权限错误遮蔽。

角色编辑器分别显示 `rolePermissionDelegationDenied`（缺少委派权限）、`rolePermissionUnavailable`（目录中已不存在的权限）与 `registrationRoleInUse`（默认注册角色限制），不再把这些业务拒绝描述为令牌过期。版本冲突和授权上下文变化仍保留原错误代码。
