## Polish bundle UI 验收

使用仓库内合成文件 `example-pl-PL.language-bundle.json`。我点击页面“选择语言包文件”按钮，打开 macOS 原生文件选择器，在目标目录选中该文件并确认；没有通过程序化 file input 赋值或 API 上传。预览显示：新增 3、重复 0、覆盖 0、未知键 0、回退 944。通过页面确认导入后，管理页 locale 选择器出现 `Polski`，公开接口显示 `pl-PL` 为非内置、已启用、版本 1、947 个有效键。

将 locale 选择为 Polski 并搜索 `localizationManagement`，页面显示：

- 源文案：`Localization management`
- 有效译文：`Zarządzanie lokalizacją`
- 来源：`管理员覆盖`
- 状态：正常

刷新管理页后默认页面筛选回到简体中文；重新选择 Polski 并搜索同一键，波兰语覆盖仍在，确认数据库保存成功。

从页面导出的文件为 [`pl-PL.language-bundle.json`](/Users/johntao/Downloads/pl-PL.language-bundle.json)。文件检查结果：`formatVersion=1`、`locale=pl-PL`、`displayName=Polski`、`sourceLocale=en`、`fallbackLocale=en`、`releaseVersion=1`、`effectiveTextCount=947`、`messages` 共 947 项；3 个导入键为 Polish，其余有效文案回退到 English。

## 全局 Polish 消费与恢复

在约定的短暂独占窗口内，通过全局语言菜单切到 Polski：

- `/dashboard/localization` 标题显示 `Zarządzanie lokalizacją`；导出按钮显示 `Eksportuj pełny pakiet językowy`；表格中的导入键显示 Polish 覆盖。
- `/dashboard/modules` 路由仍可打开；该合成 bundle 未提供模块页用语，因此对应界面文案显示 English fallback。
- 刷新模块页后全局切换器仍显示 Polski。
- 随后恢复为 `zh-CN`，检查管理页顶部语言为简体中文；已通知并行验收者可以恢复使用共享 Edge profile。普通用户的独立 profile/session 未提供，故普通用户权限不在本轮结论内。

## 合成数据清理与末态

本轮没有 locale 删除 UI，内置键也被常规条目删除接口保护。导入前公开接口没有 `pl-PL`；清理前在本地 `lumira_next` 数据库确认只有本轮创建的 `pl-PL` registry/release 和 3 条合成覆盖，三条 entry 的 `translations` 仅含对应的 Polish 键值，`created_by/updated_by=admin`，版本为 1。因无 UI 删除路径，使用带完整内容、actor、built-in 状态及条数前置条件的单事务清理了这些记录；没有修改其他 locale/key，也没有删除审计轨迹。

清理后数据库计数为 `locale=0, release=0, active pl-PL entry=0`；公开接口恢复 8 种内置语言；管理页语言列表不再显示 Polski。全局偏好为简体中文。仓库中的合成输入 fixture 保留，下载的导出文件作为验收结果保留。
