## 已修复并进入当前构建的发现

| 发现 | 修复与当前证据 |
|---|---|
| `Set.of(...).contains(null)` 会抛 NPE | 配额角色校验、角色校验/分配和组织成员分配统一改为显式 null stream 检查；保留对 null 输入的拒绝。定向测试与全量 Maven verify 通过。 |
| 敏感词检查展示 20 条时，尾部 BLOCK 规则可能被隐藏 | 全文扫描仍统计命中数并计算阻断；响应报告总命中与阻断是否出现在已展示项；前端提示隐藏阻断。已有 V14 UI 曾验证 20 项展示与隐藏 BLOCK，但按最新验收要求仍须完成新的 22+ 命中阈值 UI 回归。 |
| 监控一次失败后轮询间隔持续变慢 | 刷新间隔改用可在成功后归零的 `fetchFailureCount`，逻辑提取为纯函数；针对测试 3/3，进入最终构建。新的 UI 故障恢复周期尚未复测。 |
| 敏感词分类只能写自由文本且字典保护不完整 | V15 建立并种入敏感词分类字典；创建、编辑、导入、过滤消费启用项，显示保留原值回退；活动引用保护允许软删除后清理。字典策略保护和引用适配器进入全量 verify。 |
| 资料字段 SELECT 配置不能安全选择已有字典 | 增加按独立 `platform:dictionaries:read` 权限查询的字典选择器；缺权限或请求失败保留编码文本回退。已通过当前 Node 24 全量 typecheck/build；选值/保存/资料消费 UI 尚未验证。 |
| 工作台提示称首页组件未部署但首页入口实际可用 | Home 文案改为工作台操作提示并补齐 8 种语言，已进入 948-key 构建；更新后的页面文案未在浏览器复看。 |
| schema smoke 的 AI 内置页面清单落后于种子和路由 | 修正严格期望清单，不放宽为匹配任意 `ai-*`；schema smoke 已通过。 |
