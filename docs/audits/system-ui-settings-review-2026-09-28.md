## 源码改动

- 新增共享 `EllipsisText`，在悬停或键盘聚焦时显示完整内容；审计列表和导航树的长文本列使用该组件。审计列设定宽度并允许容器收缩，导航列设宽并将操作保持单行。
- `SettingsSection` 默认不再要求日常设置填写变更原因；安全和通行密钥设置继续要求原因。历史恢复同样遵循此区分。后端为空原因时记录系统生成的保存/恢复说明，恢复说明包含来源版本。
- 水印表单改为固定文字、个性化文字和图片三种模式，只显示当前模式需要的内容字段；后端忽略非个性化模式的模板。浏览器烟测改用键盘切换选项，避免依赖英语标签。
- 反馈列表以全部反馈为管理员默认页、我的反馈为次级页；服务层继续按角色和所有权限定访问。
- 资料字段允许编辑展示名称；创建时生成稳定字段键并保持只读，选项仅用于 SELECT 字段。
- SELECT 资料字段新增字典选择器，复用现有字典分页搜索列表并仅提供启用字典；根据独立的 `platform:dictionaries:read` 权限显示。无该权限或列表请求失败时保留原字典编码文本输入，当前停用或不在已加载页的字典编码作为禁用选项保留。只改 `profile-fields-page.tsx` 和设置模块权限传递，不新增 API/迁移；已进入 Node 24 typecheck/build，真实选择、刷新和资料值消费待 UI slot。
- 品牌、水印、协议、维护四个既有路由共享“个性化设置”页签组；维护表单将标题、说明和允许角色前置，保留结束时间、启停、历史和回滚入口。
- 导航树默认折叠、筛选时展开命中祖先，布局与组织树一致。模块页对旧 API 响应增加兼容：缺少 `core` 时从 `required` 推导，且始终把 `audit-console` 归为核心模块。
- 补齐 8 种语言的新文案。没有为本轮功能新增数据库迁移；仓库中已有的 V14 语言注册迁移属于并行任务，本轮未修改它。

### 反馈页与本地化接口补充

随后发现反馈选项对象可能缺少 `categories`，页面原先直接读取 `choices.categories.length`，会在表格渲染时抛异常。现在对分类、状态、优先级数组和默认策略做了安全归一化；缺少分类时显示持久警告并禁用提交，列表和详情仍可渲染。没有改 i18n 文案。

当前源码的 `FeedbackCatalog.Catalog` 契约要求 `policy`、`statuses`、`priorities` 和 `categories`；`/api/feedback/options` 受 `platform:feedback:read` 权限保护。源代码中的 `/api/public/localization/locales` 则声明为公开 GET。浏览器报告该公开端点返回 403；无 Cookie 的本机只读请求实测返回 401，而同服务 `/api/public/localization/bundle/en` 返回 200。这个运行时响应与当前源码权限声明不一致，应作为独立授权/运行版本问题排查，不能归因于反馈分类契约。

反馈空值修复后再次运行前端 typecheck，通过。之后统一 build 和服务启动已恢复；由于 Mac 锁屏，本轮没有用浏览器重测该修复。

### CSV 导出预检（待 UI 复现）

源码检查显示 `CsvWriter` 当前只做 CSV 引号/逗号/换行转义，没有对以 `=`, `+`, `-` 或 `@` 开头的字符串做电子表格公式中和；用户展示名校验仅限制非空与长度，因此存在公式注入候选风险。尚未创建或导出合成用户，不能记为已确认漏洞。用户页导出链接复用当前列表筛选参数，后端导出也使用同一查询过滤。后续仅在管理员 UI 创建一条唯一用户名、公式型展示名的 QA 账号；先确认筛选结果总数为 1，再点击导出，只检查该合成行的 CSV 字节内容，不用表格软件打开；若筛选不能确认收敛到一条，停止下载。完成后通过 UI 软删除该账号。

OWASP Web Security Testing Guide 建议在原始 CSV 中检查单元格是否仍以公式触发字符开头，并提醒 Excel 可能在另存/重开时移除普通引号或转义；其 Excel 缓解建议会在单元格前加制表符，但制表符会成为导出文本的一部分，因此需根据该用户导出面向的使用方式选择策略，且不存在适用于所有表格软件和机器读取场景的通用转义方案。[OWASP CSV Injection 测试指南](https://owasp.org/www-project-web-security-testing-guide/latest/4-Web_Application_Security_Testing/07-Injection/21-CSV_Injection/)。本轮尚未选定或应用修复策略。
