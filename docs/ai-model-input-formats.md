# 模型附件格式

模型接入编辑器为每个已选模型配置 `modelFileFormats`，键为模型 ID，值为小写扩展名数组。文档由平台提取文字后加入消息，PNG/JPEG 图片经过图片校验和归一化后通过 OpenAI 兼容的 `image_url` 内容块发送。模型格式选项只包含平台已有的附件读取格式；不接受任意扩展名。

该配置通过 `AiModelInputSettingsPort` 存储在设置模块的 `platform_setting` 中，section 为 `ai-model-input-{providerId}`。配置与提供方新增、修改、删除在同一事务中提交，并沿用提供方版本校验、权限检查和审计。附件设置不包含密钥，不改变工具调用能力或用户管理权限。它不属于全局设置编辑及恢复接口。

未配置某个模型时默认允许文档格式；官方 DeepSeek Flash 及其 Flash 兼容名称默认允许 PNG/JPEG 图片。未知模型不会仅因提供方名称而获得图片能力。模型发现返回的图片元数据可以为新选模型预选图片格式，管理员保存后以配置为准。空数组明确禁用附件。旧客户端省略整个配置时保留已有选择，并清理已移除模型的设置。

聊天模型目录、上传选择器、粘贴和拖放、切换模型后的附件检查及后端消息校验使用同一份格式配置。配置图片格式不会授予工具调用能力。后端不再为每次图片请求额外调用远端模型目录，以免缺失元数据误判已配置模型。

DeepSeek 图片协议依据：[官方 Vision 文档](https://api-docs.deepseek.com/guides/vision/)。该供应商还支持 GIF/WebP，但平台当前附件读取器只提供 PNG/JPEG 图片选项。
