## 后续修复补充

字典导入超时已定位：Ant Design 加载图标退出动画节点仍带有 `loading` 可访问名称，导致按钮实际名称变为 `loading 预览并校验`，精确角色查询无法命中；并非 Excel 解析失败。已增加共享 AsyncButton，稳定名称、忙碌状态及禁用行为，复用到预览、保存、登录、文件上传、字典导出、列表刷新、查询重试及加载更多。TXT/XLS/XLSX 浏览器流程和延迟响应下的忙碌状态检查通过。品牌配置确认按钮的同类超时也已修复。完整 `pnpm test:browser` 十个脚本已全部通过，类型检查、11 项前端测试和生产构建通过。以下“本轮验证”保留最初检查结果，不能把单项修复理解为全系统完成。

检查对象为 lumira-next、本地前端 8010 和后端 8090。本文更新旧 current-state-audit.md 中已过时的测试数量和文件能力描述。结论：公共平台已部分落地，尚未全量完成，不能作为旧系统完全替换或高并发、高可用验收结果。
