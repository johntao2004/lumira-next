# 模块与插件生命周期

平台保留“核心模块”“可管理模块”两个标签页。核心模块随宿主部署，不显示重复的核心标签、安装入口或卸载操作。可管理模块列仅显示名称，支持导入完整 `.lumira-plugin.zip` 安装包、安装预检、在线安装、启停、卸载预检与在线卸载。

工单反馈、运行时本地化、敏感词策略的前后端实现位于根目录 `plugins/`，不进入宿主静态 JAR 或页面构建。安装的运行文件位于 `.runtime/plugins/`；源码、发布包、运行目录与数据库分开管理。详细开发和安装契约见 [插件开发与运行](plugins.md)。

审计查询同样由 `plugins/audit-console` 的独立前后端包提供。内核保留审计写入和共享存储，通过只读 `AuditQueryPort` 提供查询；查询插件不拥有审计表，不声明可删除的数据集，也不携带数据库迁移。卸载查询插件撤销查询接口和页面，保留已有记录、角色授权和内核审计写入；重装后恢复原有 `/dashboard/audit`、`/api/platform/audit` 和 `platform:audit:access`。该历史权限码只为 `audit-console` 提供精确兼容，不开放整个 `audit` 命名空间。

已有数据库切换到此实现前，应准备并预检审计插件安装包；不得通过修改 B52、重写迁移历史或重建数据库完成拆分。新宿主上线后按插件安装流程导入、安装并启用审计查询，再验证原记录和原授权。固定清单集群需将新包纳入批准清单并按插件图变更流程部署，不能把新增插件当作相同插件图的普通滚动发布。

## 状态与授权

模块 `version` 是代码版本，`stateVersion` 是启停并发控制版本。核心模块始终启用；插件必须同时处于已安装、已启用、运行能力已发布状态才可访问。卸载与停用都撤销接口、页面及扩展提供者。

`GET /api/platform/modules` 要求 `platform:modules:read`；`PUT /api/platform/modules/{id}/state` 要求写权限、全局数据范围、CSRF，以及 enabled/version/reason。旧版本和依赖冲突返回 409，缺字段和非法原因返回 400。无变化请求保留原版本且不增加审计。权限在执行前再次检查，普通角色不会自动获得新插件权限。

专用模块历史按钮、抽屉、查询接口和修订写入已删除。`platform_module_revision` 与旧包登记表的既有记录保留，但运行代码不再查询或写入。实际操作进入平台统一审计，状态版本继续参与并发控制。

## 安装与卸载

导入检查文件摘要、压缩包边界、SDK/平台版本、入口、类、宿主类重复覆盖与完整依赖图。相同字节包重复导入幂等；同版本不同内容、已安装模块的其他版本被拒绝。升级须先卸载现版本，再导入兼容的新版本；业务数据保留。

预检给出安装、复用、启用、卸载清单与阻塞原因，并返回整个状态图的 revision。执行再检查 revision，生命周期操作在单实例内串行化。依赖先于使用者安装，所有健康检查通过后开放访问。失败撤销本次新增运行能力及安装状态；插件包中已经成功执行的数据库迁移不会随生命周期操作回滚。

卸载检查所有已安装消费者，包括停用的消费者。停止接收请求，等待 HTTP、SDK 扩展调用及托管任务完成，依次撤销映射、调度、订阅、页面与 Spring 子容器。无人引用的自动依赖递归清理；核心依赖、显式安装依赖和仍被其他插件使用的依赖保留。

卸载默认保留业务数据和配置，也可选择删除所选插件清单声明的数据。删除预检显示范围与数量，要求输入插件标识并二次确认；各数据集在同一事务清理，失败全部回滚。闲置自动依赖的数据、授权、共享文件、表结构与插件独立迁移记录始终保留。平台重启校验持久制品并按安装状态恢复；中断的生命周期任务标为 FAILED，当前安装记录经恢复校验后加载。损坏制品或恢复失败会阻止平台声称插件就绪，需要管理员修复制品后重启。

## 宿主数据库与插件初始化

新建宿主数据库由 `backend/src/main/resources/db/migration/B52__platform_initialization.sql` 建立当前全局表结构、约束、索引、函数、视图和稳定种子。宿主仅提供当前全局初始化基线，不提供旧全局 Flyway 历史的升级兼容。插件安装包中的 `migrations/` 仍由每插件独立的 Flyway history 管理；安装、升级和卸载按插件清单与[插件开发与运行](plugins.md)中的规则执行。

## 验证边界

后端数据库测试、构建检查、真实 HTTP 生命周期和实际浏览器操作分别验证。单实例与可信自研插件是当前边界；不提供插件市场、多实例一致性或不可信代码隔离。临时日志和截图在 `.runtime/plugin-work/`，不进入架构文档目录。
