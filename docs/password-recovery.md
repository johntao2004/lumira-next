# 密码找回

当前已实现内部凭证存储、PasswordRecoveryService，以及 POST /api/auth/password-recovery/request 和 /confirm 两个控制器。已接入加密邮件入队、八语言邮件模板、密码规则及审计；登录页“忘记密码”抽屉也已接入。实际收信端到端验收仍未完成。

宿主初始化基线 `B52__platform_initialization.sql` 通过 `platform_password_reset` 为每个账号保存一份当前密码重置挑战。复用 VerificationToken 的 256 位随机值和 SHA-256 摘要，原始令牌不入库。只允许已启用账号及已验证邮箱；待验证邮箱不能用来找回密码。请求返回可投递的已验证地址，调用服务须在同一事务中创建加密邮件任务和审计。

挑战有效期、冷却时间、每日请求上限和失败确认上限均读取安全策略（默认分别为 600 秒、60 秒、10 次和 5 次）。新挑战替换旧挑战；成功消费清除令牌、密码摘要快照和邮箱版本，保留请求计数，避免成功重置绕过冷却和日上限。账号删除时级联清除挑战。

挑战绑定签发时的密码哈希和邮箱版本。密码修改、邮箱版本变化、账号禁用都会阻止旧挑战消费。这里的 password_snapshot 是已有的单向密码哈希，不是原始密码；消费后清空。服务层不得将该字段返回接口或日志。

consume 只接受可信服务提供的编码后密码。锁顺序为账号、邮箱、重置记录，与邮箱绑定服务保持一致。密码更新、该账号所有会话撤销和挑战消费在一个事务中完成；并发消费只能成功一次。调用方的审计失败可以回滚全部变化。错误确认返回 false，使失败计数能够提交；公共 API 的错误转换必须在服务事务之后。

服务层在查询账号前检查全局 SMTP 可用性。未知、停用、未验证和冷却中的账号均正常返回 void，不返回邮箱或令牌；具备条件的账号在同一事务中创建挑战、加密邮件和审计。此行为只是统一响应基础，不代表时间侧信道已经消除。

PasswordPolicy 统一密码修改及找回的长度/UTF-8 字节限制；新摘要使用版本化 Argon2id，遗留 BCrypt 只在读取时兼容。确认对未知账号同样执行密码编码，但账号存在时仍有额外数据库工作，不能据此宣称恒定时间。仅在证明有效后执行禁止使用原密码的检查；避免在证明前通过该错误探测账号。确认结果为 false 时先提交失败计数及审计，再由未来 API 转换错误响应。

公共接口要求 CSRF，JSON 请求体最多 2048 字节；仅精确匹配的 POST 路径允许匿名调用，GET 不消费令牌。request 接受 username/locale，正常返回空 202；confirm 接受 username/token/newPassword，成功空 204，无效证明在服务提交后返回 400。验证码和新密码标记为 JSON 只写，确认 DTO 的诊断字符串已脱敏。

PasswordRecoveryLimiter 使用独立提交的 PostgreSQL 分钟桶，默认同一来源每分钟 60 次、同一规范化账号每分钟 10 次，请求与确认共用计数。来源先被限制，避免达到来源上限后继续创建随机账号桶；复用 ClientAddressResolver 的可信代理规则，不任意信任转发地址。部署在共享出口下可能需要根据实测调整限制；账号冷却和每日限制仍由内部存储执行。

登录页复用 PlatformDrawer、AsyncButton、NewPasswordFields 和统一 API 客户端，提供账号、验证码、新密码及确认输入。请求只校验账号，反馈为统一的条件式入队提示；确认后清空密码，成功返回登录页、保留账号并要求重新登录，不自动建立登录会话。独立表单名称防止与登录表单的 username ID 冲突。

真实浏览器回归通过请求提示、无效/有效验证码、失败后的密码清空、390px 布局以及重置后新密码登录。发信请求被拦截、挑战由独立数据库夹具提供，没有发送外部邮件，因此实际收信端到端测试仍待完成。不要通过 GET 自动消费令牌。

TLS 传输集成测试使用真实 PostgreSQL 配置和加密凭据、实际 SmtpConnectionSource、PasswordRecoveryService、加密队列、Worker 与 Angus TLS 传输。服务签发的邮件经回环 SMTP 服务器接收并解析，收到的验证码成功重置密码并撤销本账号会话，重复消费失败；临时证书信任仅注入测试传输工厂，新密码摘要按当前密码策略更新。测试未修改生产信任配置或主库邮件设置。此项通过服务层编排调用，未覆盖同一次测试中的 HTTP 控制器、浏览器或外部收件箱。

真实 PostgreSQL 隔离测试覆盖启用/已验证条件、会话隔离撤销、单次消费、过期、替换、失败上限、密码/邮箱变化失效、冷却和日上限、外层事务回滚、并发消费、外账号令牌拒绝及级联删除。没有发送外部邮件。
