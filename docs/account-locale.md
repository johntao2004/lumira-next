# 账号语言偏好

登录页与后台共用语言菜单。匿名访问时，语言保存在当前浏览器；登录后，用户主动选择的语言保存在自己的账号中。以后在另一浏览器登录或刷新页面时，前端读取账号偏好并应用。深色主题仍保存在浏览器中。

账号暂未保存语言时，登录后沿用当前浏览器最后缓存的语言，不自动写入账号；这个浏览器偏好可能来自之前登录的另一个账号。账号语言读取失败时也保留当前浏览器选择；保存失败时保留本次浏览器切换，并提示用户账号没有更新。

接口使用现有 Cookie 会话和 CSRF 防护，服务端从登录主体确定账号，不接受客户端指定用户名：

| 方法 | 路径 | 请求/响应 |
| --- | --- | --- |
| `GET` | `/api/account/locale` | 返回 `{"locale":"zh-CN"}`；未设置或当前语言已停用时返回 `{"locale":null}`。 |
| `PUT` | `/api/account/locale` | 接收 `{"locale":"zh-CN"}`，验证语言格式及注册状态后保存并返回规范化语言标记。 |

支持 BCP 47 语言标记。本地化插件启用时，服务按语言注册表接受已启用的语言，包括注册的内置语言；插件卸载或不可用时，服务回退到内置八种语言。停用的账号语言不会被清除，重新启用后仍可恢复；它在停用期间不会覆盖浏览器选择。

`platform_user.preferred_locale` 使用可空列保存账号偏好。空值用于兼容已有账号，使其首次登录时继续使用原有浏览器偏好；迁移见 `V24__account_locale_preference.sql`。偏好更新不会增加个人资料版本，也不会修改其他账号或业务数据。
