# 事件管理插件

提供现有 `/dashboard/event-outbox` 页面及事件查询、事件/操作追踪和死信重放接口，依赖 `platform@1.0.0` 和 `events@1.0.0`。

`node scripts/build-plugins.mjs event-console` 构建独立安装包。通过插件管理导入、安装或保数据卸载。共享事件队列、worker 和恢复存储属于内核；管理插件卸载期间已提交事件继续投递。插件不声明删除数据集，不修改 B52 或已应用迁移历史。

重放同时要求原页面访问和重放权限，操作追踪继续要求全局审计权限。重放保持原事件幂等和代次校验，审批历史与原事件在卸载、重装后保留。
