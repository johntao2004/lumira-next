# 个人文件插件

`personal-files` 拥有“我的文件”的页面、首页文件用量卡片及专属样式、账号文件 API、列表与回收站查询流程、所有者边界、版本化回收/恢复/彻底删除和对应审计。仅依赖内核 `identity` 与 `files` 的稳定契约，不引用其他插件的私有实现。

内核 `files` 保留共享元数据与 Blob 存储、上传预留和配额互斥、图片标准化、文件预览以及提交后物理删除。头像、站点图片、模板、反馈和 AI 附件可以继续使用这些基础能力；个人文件管理插件卸载时不删除它们或现存文件。

插件没有初始化 SQL，不重写 B52 或既有文件记录。菜单仅接管 B52 中固定的“我的文件”行，保留身份、标签、布局和状态。所有账号端点保持登录要求，实际操作仍解析当前所有者；没有额外的管理权限引导或跨用户访问。
