# AI 工作台

`ai` 提供模型接入管理、对话、待确认操作、附件读取和对话分享。实现与页面由独立包提供，依赖身份、平台、目录、存储和设置内核。目录查询通过共享的 `DirectoryAiServicePort` 租约执行；本地化 1.0.13 通过 `AiTextGenerationServicePort` 声明对 AI 的直接依赖。旧 SDK 的文本生成接口由内核桥接到当前提供者，不缓存实现对象。

保留 ai-console / ai-models 的 URL、有限历史权限别名、全局委派规则和既有对象范围。B52 中两条固定菜单在严格匹配 ID、路径、权限和范围后从 platform 归属迁入本插件，保留名称、排序和状态。本包不包含重写全局结构的 SQL；模型、分享、待确认操作、设置历史和加密凭据均保留在原表中，卸载仅支持保留数据。

本插件用托管资源运行待确认操作清理任务，在发布后启动、卸载时排空和撤销。卸载 AI 之前需显式解除已安装的本地化消费者；卸载目录之前需显式解除 AI。运行时拒绝循环依赖和不匹配的依赖版本，不会自动卸载消费者或无人引用的提供者。

公开分享保留 `/share/ai/:token` 的兼容入口，宿主的通用只读会话视图只负责渲染；内容读取、校验、存储、更新和撤销由本插件提供。卸载后相应 API 撤下，原有分享内容无法继续读取，重新安装后恢复同一记录。

构建 `pnpm plugins:build ai localization`。真实验收脚本 `scripts/ai-plugin-lifecycle-smoke.py` 使用显式绑定的独立 QA 数据库和本地模型 HTTP 夹具，覆盖模型 CRUD、分享、加密数据保留、依赖阻断与装卸；`scripts/ai-plugin-browser-smoke.mjs` 单独验证动态页面、公开分享、刷新和响应式布局。这些脚本不得指向业务数据库。
