# 全部文件管理插件

`file-console` 独立拥有管理员文件列表与回收站查询、下载/预览权限、带版本与引用护栏的删除/恢复/永久删除业务、系统配额设置及页面。它依赖基础存储 `files` 和基础配置存储 `settings`。

原始字节存储、限额执行、个人文件接口、头像/附件和清理 worker 留在内核。业务通过 `FileManagementStoragePort` 调用有界读取及已提交删除的扫尾，不导入私有存储实现。管理插件卸载不会删除文件、配额设置或历史，个人文件与已保存配额继续生效。文件保留策略编辑器通过可选的嵌入路由显示，缺少该管理插件时文件中心继续可用。

永久删除在事务中先将元数据改为 `DELETING`。嵌套事务尚未提交时，物理删除保留在队列中，防止外层回滚后丢失本地字节；已提交的待删除记录由内核重试清理。普通顶层请求保持提交后直接扫尾的既有行为。
