# 工单反馈插件

这是 Lumira 的独立插件，包含完整前后端源码与插件清单。

运行 `pnpm plugins:build feedback`，安装包生成在 `dist/feedback-1.0.13.lumira-plugin.zip`。在平台模块的可管理模块页导入并安装。

反馈页访问、按角色数据范围读取、本人提交、状态修改和回复分别授权。列表、详情与图片通过 `/api/feedback/manage` 按读取权限及目标记录范围过滤；只有详情响应确认当前记录可修改状态或回复时，前端才显示对应操作。仅有提交权限的角色可读取提交选项并提交反馈，但不会加载列表。

依赖：platform, identity, files, dictionaries, notifications。默认卸载保留业务数据、配置、源码与发布包；选择保留数据后重新安装兼容版本恢复使用。

卸载时可选择保留数据，或删除清单 `dataSets` 声明的业务记录。删除不可恢复；依赖插件的数据、共享文件、权限授权及迁移记录保留。
