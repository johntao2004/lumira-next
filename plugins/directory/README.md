# 组织与目录插件

`directory` 提供用户与角色管理、组织树、在线会话管理和打印模板。业务控制器、服务、仓储与页面均在独立包中；依赖 `identity`、`platform` 和 `files` 存储内核。宿主仅保留登录、账户创建与版本、授权投影、会话基础设施、文件存储及角色配额执行等基础能力。

本插件使用 SDK 2 的逐权限范围规则，保留现有 URL、页面权限、对象范围和全局委派要求。多页面操作的权限按 AND 组合；角色读取的可选动作仍按 OR 组合。清单中的字面路径排在变量路径之前，与宿主运行时的首项匹配行为一致。

用户、角色、组织、成员关系、模板和版本由 B52 初始化管理，本包不重写全局迁移、不删除这些数据。卸载只支持保留数据：先检查依赖和运行中调用，成功卸载后撤下业务路由、页面及服务；再次安装恢复原有记录及其标识。认证与已存角色配额继续有效。需要目录业务服务的调用通过共享契约和运行时租约解析提供者，不能缓存实现 Bean。

运行 `scripts/directory-plugin-lifecycle-smoke.py` 和 `scripts/directory-plugin-browser-smoke.mjs` 需显式配置带 QA 标记的独立数据库及绑定服务；不得用本地业务配置执行。生命周期验证包含范围授权、角色与组织关系、模板 PDF、保数据装卸、卸载期间登录和存储配额。浏览器验证是单独的验收步骤。
