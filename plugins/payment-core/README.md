# 支付核心与订单

`payment-core` 是扫码支付配置、订单与全额退款状态机插件。它通过稳定 SDK `common.PaymentGatewayPort` 和宿主 `PluginExtensionsPort` 调用已启用的渠道插件，不引用微信或支付宝实现。

渠道 ID 固定为 `wechat-pay` 与 `alipay-pay`。先安装并启用本插件，再按需安装渠道插件。工作台提供全渠道订单查询与二维码下单；渠道插件各自提供渠道设置和订单入口。所有支付权限均为全局范围。安装、HTTP/JSON、回调安全、配置轮换、运营限制和验收边界见[支付插件说明](../../docs/payments.md)。

订单与配置历史存于插件专属表。渠道 secret 通过平台加密 SecretStore 保存，工作台和 API 不回显密钥；选择删除支付核心插件数据时只清理其微信、支付宝两个精确 secret 上下文。密钥历史 vault 有 48 KiB 限额，达到后保存会明确失败。

后台每 30 秒最多对账 20 笔待恢复订单或退款。外部网络超时保持未知/处理中，沿用原商户单号与退款号；仅匹配本地订单的签名成功通知或渠道查询能确认支付/退款成功。本插件的合成单元测试不产生真实资金操作。
