# 文件保留策略插件

`file-retention` 负责保留策略的编辑、版本冲突、历史查询、回滚与管理页面，依赖基础 `files` 和 `settings`。卸载只撤回管理入口，持久化策略、历史版本和文件数据保留；内核清理继续按原策略执行。

自动策略保存或回滚在同一事务中最多将 100 个过期回收站文件标记为待删除，其余由内核的有界周期清理推进。该行为避免一次保存扫描并锁住整个历史回收站。标记和审计一起提交，实际存储删除仍由带版本护栏的内核收尾执行。

从已有部署切换时安装此包，并验证全局访问及更新权限；不可用模块安装权限绕过原保留策略权限。无需修改 B52 或重写数据库迁移历史。
